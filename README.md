[📖 Integration Documentation →](integration/README.md)

## 📊 Plugin

**[Octopus Energy España Consumption Card](plugin/)** - Lovelace card for displaying consumption graphs and tariff comparisons.

[📖 Plugin Documentation →](plugin/README.md)

## 🚀 Quick Start

### Install Integration

1. Open **HACS** in Home Assistant
2. Go to **Integrations**
3. Add custom repository: `https://github.com/bthos/ha-octopus-energy-es` (category: Integration)
4. Install **Octopus Energy España**
5. Configure via **Settings → Devices & Services**

### Install Plugin (Optional)

1. Open **HACS** in Home Assistant
2. Go to **Frontend** (or **Plugins**)
3. Add custom repository: `https://github.com/bthos/ha-octopus-energy-es` (category: Plugin)
4. Install **Octopus Energy España Consumption Card**
5. Add card to your Lovelace dashboard
